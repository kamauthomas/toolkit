## Favicon investigation

The current homepage returns 200/release `2026.10.27.1` and emits WordPress-managed declarations for:

- `…/cropped-image-5-removebg-preview-32x32.png`
- `…/cropped-image-5-removebg-preview-192x192.png`
- `…/cropped-image-5-removebg-preview-180x180.png` as the Apple touch icon.

The 32 and 192 downloads are valid square PNGs and visually contain the official Toolkit mark, not WordPress. Their SHA256 values are `6439c09f9f839e85c2c810c383e6a925d25bfc1ce043e3f30c8c9ae5c821b372` and `f2d8685730ff7c808f450f8c267ab07c86b7714a29f743259ce37970c64573c3`. The 180 icon was declared but not independently downloaded; no unsupported claim about its pixels is made.

The fetched robots file does not disallow the homepage or these uploads for Googlebot/Googlebot-Image. Normal-client success and the correct Google screenshot support current availability; they are not a fresh authenticated Googlebot network trace. The web fetcher failed to read some resources that direct normal requests subsequently read; that alone is not evidence of crawler blocking.

**The initial `https://toolkitafrica.ac.ke/favicon.ico` request returned 404.** This was a real compatibility gap for clients that rely on the conventional root path. It did not invalidate the correct declared icons, and the evidence does not prove Brave requested that path or cached the old WordPress image for that reason. The most likely explanation for the engine difference is older Brave favicon/index data; retain that as an inference, not a demonstrated cache trace.

Google's [favicon requirements](https://developers.google.com/search/docs/appearance/favicon-in-search?hl=en) use homepage icon declarations and require a stable, crawlable square brand icon. Its preferred size is larger than 48 pixels; the current 192-pixel icon meets that size recommendation. A root ICO is useful compatibility work, rather than a prerequisite to replace currently correct Google branding. Reprocessing is controlled by the search engine; changing an asset cannot promise an immediate SERP refresh.
