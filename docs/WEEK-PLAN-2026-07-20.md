## Production preservation model

The rollout does not require a WordPress reinstall. The current WordPress installation remains the platform of record. The parent Eduma theme, database content, uploads, plugins, accounts, posts, and original Elementor content remain intact. The accepted child theme is added or updated, and a feature switch determines which presentation is served.

For an immediate presentation rollback, set `TOOLKIT_REDESIGN_ENABLED` to `false` and purge LiteSpeed. This returns requests to the established parent-theme/database presentation. Keep the latest pre-cutover child-theme archive and the same-day full files/database backup outside temporary storage.
