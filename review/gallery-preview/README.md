# Gallery Local Review

This preview exists so the revised image and video gallery concepts can be
approved before any demo or production deployment.

Run from the WordPress repository root:

```bash
php -S 0.0.0.0:8097
```

Review:

- Image journey: `http://<workstation-ip>:8097/review/gallery-preview/`
- Video stories: `http://<workstation-ip>:8097/review/gallery-preview/?view=videos`

The preview uses the existing Toolkit media library and YouTube
privacy-enhanced embeds. It does not write data or change WordPress.
